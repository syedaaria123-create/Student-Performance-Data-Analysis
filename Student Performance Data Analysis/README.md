# Student Performance Data Analysis

## Overview

This project analyzes student academic performance using Python.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib

## Features

- Read CSV Dataset
- Calculate Total Marks
- Calculate Average Marks
- Highest Student
- Lowest Student
- Class Average
- Median
- Standard Deviation
- Department Wise Average
- Top 5 Students
- Students Above 85
- Save Updated Dataset
- Generate Bar Chart

- Data Cleaning
- Data Analysis
- Data Visualization
- CSV Handling
- Statistics
- Python Programming
